# Security

This repository is a public implementation kit based on public standards and synthetic examples. Do not upload personal, employer-confidential, client-confidential, regulated, credential, vulnerability, or other nonpublic information to a demonstration agent.

The Guidance Agent has no external tool or write capability. That reduces integration risk but does not make generated answers authoritative or deterministic. Review Copilot Studio environment security, Dataverse storage, sharing, authentication, data loss prevention, retention, analytics, and administrator controls before organizational use.

The Structured Assessment track is a derived low-code implementation. Treat changes to its flow, variables, branching, knowledge, instructions, or source versions as governed changes requiring testing and qualified approval.

Do not include sensitive information in a public issue. Use GitHub private vulnerability reporting when available.
