# Knowledge source descriptions

Use these descriptions when adding the generated files to Copilot Studio.

## control-library.md

Framework 1.2.0 control catalog containing authoritative control objectives, requirements, applicability statements, structured applicability explanations, evidence examples, implementation notes, and public-reference identifiers. Use this source to explain controls. Do not use it to calculate a risk tier.

## guided-intake.md

Control Plane 0.6.0 assessment questions, supported structured values, inference safeguards, and risk-tier terminology. Use this source to guide fact collection and identify missing information. It does not authorize model-generated tier assignment.

## provenance-and-boundaries.md

Pinned source versions, authority boundaries, permitted uses, limitations, and human-review requirements for the implementation kit. Use this source whenever the user asks about authority, provenance, reliability, or appropriate use.
